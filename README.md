# DATA-VALIDATION-SYTEM
AN application that captures personal information and validates every field in real time before accepting the data.

 Features
- Modern, non-default Swing interface with a professional colour scheme
- Real-time validation with clear error messages next to each field
- Support for the following fields:
  - Name
  - Surname
  - Student / ID Number
  - Age
  - Gender (radio buttons)
  - Contact Number
  - Email Address
- Save, Clear and Exit functionality
- Helpful, non-technical error messages for the user

 Validation Rules

| Field              | Checks Applied                                      |
|--------------------|-----------------------------------------------------|
| Name               | Presence, Type (letters only), Length (min 2)       |
| Surname            | Presence, Type (letters only), Length (min 2)       |
| Student / ID Number| Presence, Type (digits only), Length (8–13 digits)  |
| Age                | Presence, Type (number), Range (16–100)             |
| Gender             | Presence (must select one option)                   |
| Contact Number     | Presence, Format (10 digits starting with 0)        |
| Email Address      | Presence, Format (valid email pattern)              |
